# 路子 · 每天一个能落地的搞钱方法

一个本地优先、不用注册的安卓 App。不推荐理财产品，不卖课，只收录**今天就能动手做**的搞钱路子和平价省钱攻略。

- 100 条搞钱路子，每条配当日可执行的打卡清单
- 46 条省钱攻略，带花费时长、收益区间和周期提醒
- 记账、连续打卡、目标与金币激励全部本地运行

> 所有收益数字都是预估区间，实际以平台当期规则为准。App 内置免责说明，不承诺任何收益。

## 功能

### 路子库
- 按十类浏览、搜索、难度与启动资金筛选
- 「今日路子」按日期轮换，每天一条，配当天就能做的一步
- 打卡清单、连续天数、里程碑金币奖励
- 收入 / 支出记账，月度统计与趋势图

### 省钱攻略（v4.47 新增）
- **今日可省**：按星期和日期自动筛出今天能做的活动，首页入口条直接可见
- **搜索筛选排序**：分类、5 分钟内、收藏、推荐 / 省得多 / 最省事 / 最新验证
- **资格状态机**：`没做过 / 还有资格 / 已用完`，标记「已用完」后自动从今日清单消失，避免白跑一趟
- **时效提示**：每条攻略带最后验证日期，超过 90 天显示「可能已过期」并降权
- **省钱台账**：记一笔（金额 + 备注 + 日期），累计与本月统计、按攻略排行

### v4.48 新增
- **台账编辑与月份回看**：已记的每一笔可改金额/备注/日期或删除，台账支持按月份切换查看
- **详情页已省统计**：每一条攻略详情里直接看到自己在这条上省了多少、记过几笔
- **搜索历史与空态**：记住最近搜过的关键词，一键重搜；搜不到时给出清空条件与推荐攻略
- **本月省钱目标**：可选目标金额，首页入口条实时显示「本月已省 ¥X / 目标」，达标发放金币奖励
- **本周活动筛选**：攻略库新增「📆 本周活动」分类，按距今天数排序，已用完自动隐藏
- **首页顺手省合计**：只累计 5 分钟内可完成的活动，避免把装修、买车这类一次性大额算进当日合计
- **相关攻略推荐**：详情页底部按分类、标签与周期推荐 3 条搭配着做更省的攻略
- **今日固定清单**：按天/周/月循环的活动组成今日清单，显示完成进度；全部标记「已用完」每天可领一次 +100 金币

### 内容原则
- 只收录正规平台的公开活动，不写死会随活动调整的具体面额
- 收益一律给区间，按偏低估算，不写「月省 1000」这类标题党
- 明确不收录：批量账号、绕过风控、刷单套现、代登代操作、泄露个人数据、平台漏洞型玩法

## 技术栈

- Capacitor 6 + 原生 HTML/CSS/JS，无框架
- esbuild 打包，产物自包含到 `www/`
- 数据全部存 `localStorage`，不需要账号，也不上传任何数据到服务器
- 安卓清单里只有 4 项权限：`INTERNET`（仅用于可选的远程地址导入）、`POST_NOTIFICATIONS` / `WAKE_LOCK` / `RECEIVE_BOOT_COMPLETED`（本地提醒用），不申请位置、通讯录、相机、存储等敏感权限

## 本地运行

```bash
npm install
npm run build     # 打包到 www/，同时校验内容库与版本号
npm run serve     # 本地预览 http://localhost:5173
```

## 打 APK

需要 JDK 17 与 Android SDK。签名文件不入库，需自备 `android/keystore.properties` 与 `.jks`。

```bash
npm run build
npx cap sync android
cd android
./gradlew assembleRelease
```

产物在 `android/app/build/outputs/apk/release/`。
